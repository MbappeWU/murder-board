## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/MbappeWU/ai-prompt-templates.git
cd ai-prompt-templates
```

### 2. 选择场景

根据你的需求，选择对应的提示词模板。

### 3. 使用方法

将模板内容复制到你的 AI 工具（Claude, Codex, Gemini）中即可使用。
