# React + TypeScript 项目初始化提示词

请帮我创建一个新的 React + TypeScript 项目，包含以下要求：

## 项目配置
- 使用 Vite 作为构建工具
- TypeScript 严格模式
- 使用 pnpm 作为包管理器

## 目录结构
```
src/
├── components/     # React 组件
├── hooks/         # 自定义 Hooks
├── pages/         # 页面组件
├── services/      # API 服务
├── types/         # TypeScript 类型
├── utils/         # 工具函数
└── styles/        # 全局样式
```

## 要求
1. 配置 ESLint + Prettier
2. 设置 React Router
3. 包含基础 Layout 组件
4. 添加错误边界 (Error Boundary)
5. 配置环境变量类型

## 输出
请输出完整的项目结构和关键配置文件。
